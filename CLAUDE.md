## Стек

Чистый HTML/CSS/JS, без сборки и без npm.

| Файл | Что внутри |
|---|---|
| `index.html` | разметка + вся CSS в одном `<style>` |
| `site.js` | данные работ, сетка, лайтбокс, курсор, анимации |
| `vendor/gsap.min.js`, `vendor/ScrollTrigger.min.js` | GSAP 3.12.5 |
| `media/` | пережатые видео и постеры |

**GSAP лежит в репозитории, а не на CDN — и это осознанно.** У части российских
провайдеров прямой TLS к `cdn.jsdelivr.net` не проходит (проверено на машине
владельца: `curl` доходит, Chrome — нет). С CDN сайт у таких посетителей
оставался бы вообще без анимаций. 115 КБ отдаёт Vercel, это дешевле проблемы.

## Общая стилистика

- **Настроение:** кинематографично, глубокий чёрный, зерно и виньетка как у плёнки.
  Терминальная ДНК осталась в мелочах — моноширинные метки, зелёный акцент.
- **Ориентир по подаче:** byridge.com — полноэкранное видео на входе, плавная
  типографика, сдержанная палитра. Копировать оттуда шрифт и бирюзовый акцент нельзя,
  это соседний артист из той же команды.
- **Чего НЕ хочется:** корпоративный стиль, кислотность, перегруженность,
  «красивые» градиенты в духе Dribbble.

Порядок работ и все подписи живут **только** в массиве `WORKS` в начале `site.js`.
В HTML карточек нет — сетку собирает JS.

### Сетка

3×3, девять работ. При наведении колонка и ряд растягиваются
(`1.6fr / 0.7fr` по колонкам, `1.44fr / 0.78fr` по рядам — суммы равны `3fr`,
поэтому коробка не дёргается), соседи уходят в `brightness(.28) blur(2px)`.

Высота считается в `sizeGrid()` из ширины ячейки, чтобы в покое плитки были ровно
16:9, а `fr`-анимация шла по фиксированной коробке. Ниже 862px раскрытие
отключается, сетка становится 2 колонки, ниже 560px — одна.

## Анимации

GSAP + ScrollTrigger. Владелец просил «ярко и эффектно», но всё держится на
таймингах, а не на количестве эффектов.

| Что | Где |
|---|---|
| Интро: расшифровка слова, счётчик, шторка вверх | `runIntro()` |
| Первый экран: видео из `scale 1.14`, строки заголовка выезжают из-под маски | `initAnimations()` |
| Параллакс и затухание первого экрана при скролле | `scrub: true` |
| Заголовки секций: линия чертится, текст расшифровывается | `scramble()` |
| Появление блоков пачками | `ScrollTrigger.batch` |
| Кастомный курсор, кольцо с `PLAY` над работами | `initCursor()` |
| Магнитные кнопки | `initMagnetic()` |
| Бегущая строка | `initMarquee()` |

### Правило, которое нельзя ломать

Стартовые состояния (`opacity: 0` и сдвиги) висят на `html.js`, а класс `js`
ставится **инлайновым скриптом в `<head>`**, до первой отрисовки — иначе контент
успевает мигнуть.

Класс `html.reveal` — аварийный выключатель, он возвращает всё в видимое
состояние. Его ставят три ситуации: GSAP не загрузился, нет ScrollTrigger,
включён `prefers-reduced-motion`. Плюс таймер на 7 секунд в `<head>` на случай,
если `site.js` вообще не выполнился. **Любое новое стартовое состояние в CSS
обязано иметь парную строку в блоке `html.reveal`** — иначе при отвале скрипта
кусок страницы останется невидимым навсегда.

## Медиа — обязательный конвейер

Исходники лежат в `C:\Users\Shambooo\Videos\Portfolio` и `...\Videos\portfolio_2`,
в репозиторий **не кладутся** (4K, 15–40 МБ штука). В `media/` попадают только
пережатые версии:

| Файл | Что это | Параметры |
|---|---|---|
| `<slug>-preview.mp4` | видео в сетке | 960w, без звука, `-crf 28`, `+faststart` (~0,3–0,9 МБ) |
| `<slug>.mp4` | видео в лайтбоксе | 1920w, звук aac 128k, `-crf 22`, `+faststart` (~3–10 МБ) |
| `<slug>.jpg` | постер карточки | осмысленный кадр, 960w, `-q:v 5` |
| `reel.mp4` | ролик первого экрана | 1600×900, без звука, `-crf 26`, ~2,2 МБ |

```bash
ffmpeg -i src.mp4 -an -vf "scale=960:-2" -c:v libx264 -crf 28 -preset slow \
  -profile:v main -pix_fmt yuv420p -movflags +faststart media/<slug>-preview.mp4
ffmpeg -i src.mp4 -map 0:v -map "0:a?" -vf scale=1920:-2 -c:v libx264 -crf 22 \
  -preset medium -pix_fmt yuv420p -c:a aac -b:a 128k -movflags +faststart media/<slug>.mp4
ffmpeg -ss <кадр> -i src.mp4 -frames:v 1 -vf scale=960:-2 -q:v 5 media/<slug>.jpg
```

**`media/reel.mp4` — временный.** Собран нарезкой по 1,5–1,7 с из восьми работ.
Владелец готовит свой шоурил в After Effects; заменить = перезаписать этот файл
(и `reel.jpg` как постер). В коде менять ничего не нужно.

**Правила загрузки:**
- У каждого `<video>` в сетке обязателен `poster` — иначе до буферизации карточка чёрная
- `preload="metadata"` в разметке, `IntersectionObserver` поднимает до `auto` и запускает
- Играют **только видимые** превью: девять одновременных декодов роняют fps и батарею
- Полноразмерное видео грузится только по клику; при закрытии лайтбокса `src` снимается

## SEO / шеринг

Ссылку кидают в Telegram и в личку, поэтому в `<head>` обязаны быть:
`description`, `og:title`, `og:description`, `og:image` (`og.jpg`, 1200×630),
`twitter:card`, favicon. Абсолютные URL в og-тегах указывают на `https://cloofen.ru/`.

**`og.jpg` устарел** — он от прежней одноэкранной визитки. Пересобрать под новый
первый экран.

## Доступность

- Карточки — `<button>`, стрелки ходят по сетке, Enter открывает лайтбокс, Esc закрывает
- Фокус возвращается на карточку после закрытия лайтбокса
- `prefers-reduced-motion` выключает интро, курсор, параллакс и бегущую строку
