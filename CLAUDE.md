## Анимации и интерактивность

- **Общий тон:** Минимальные анимации. Если есть — резкие, без «ease-in-out» мыльности.
- **Вход:** стаггер `fadeUp`/`fadeIn` по элементам hero (0.1s → 1.6s)
- **Эффекты при наведении:** инверсия цвета или акцентная рамка — без scale и теней
- **Фон:** canvas с бинарным шумом (`0`/`1`, `rgba(0,60,30,…)`), перерисовка на resize через `requestAnimationFrame`
- **Смена фона по скроллу:** `body.at-works` переключает радиальное свечение hero на боковой градиент works
- **Прокрутка:** `scroll-snap-type: y proximity` **только на десктопе** (`hover: hover` и ≥900px) — на мобильных snap залипает
- **Клавиатура:** карточки — `<button>`, стрелки ходят по сетке, Enter открывает лайтбокс, Esc закрывает

## Структура

Сайт — **одна страница, два экрана**. Никаких подстраниц.

### Секция 1 — Hero / `#about`
Фото · имя · `/ Motion Designer` · мета (age / focus / based) · описание · кнопка Telegram · якорь `↓ works`

### Секция 2 — Работы / `#works`
Сетка **3×2, шесть работ**. При наведении колонка и ряд карточки растягиваются
(`1.7fr / 0.65fr` по колонкам, `1.45fr / 0.55fr` по рядам), остальные уходят в
`brightness(0.3) blur(2px)`. Клик — лайтбокс с полноразмерным видео и звуком.

Работы по порядку: Byreal · Solayer · Mr. Stephen · Sentient · Seismic · Checkout.

## Медиа — обязательный конвейер

Исходники лежат в `C:\Users\Shambooo\Videos\Portfolio` и в репозиторий **не кладутся**
(4K, 15–40 МБ штука). В `media/` попадают только пережатые версии:

| Файл | Что это | Параметры |
|---|---|---|
| `<slug>-preview.mp4` | видео в сетке | 1280w, без звука, `-crf 26`, `+faststart` (~1–2 МБ) |
| `<slug>.mp4` | видео в лайтбоксе | 1920w, звук aac 128k, `-crf 22`, `+faststart` (~3–10 МБ) |
| `<slug>.jpg` | постер карточки | кадр с 2-й секунды, 960w, `-q:v 5` |

```bash
ffmpeg -i src.mp4 -an -vf scale=1280:-2 -c:v libx264 -crf 26 -preset veryfast \
  -pix_fmt yuv420p -movflags +faststart media/<slug>-preview.mp4
ffmpeg -i src.mp4 -map 0:v -map "0:a?" -vf scale=1920:-2 -c:v libx264 -crf 22 \
  -preset medium -pix_fmt yuv420p -c:a aac -b:a 128k -movflags +faststart media/<slug>.mp4
ffmpeg -ss 2 -i src.mp4 -frames:v 1 -vf scale=960:-2 -q:v 5 media/<slug>.jpg
```

**Правила загрузки:**
- У каждого `<video>` в сетке обязателен `poster` — иначе до буферизации карточка чёрная
- `preload="metadata"` в разметке; на десктопе JS поднимает до `auto` и запускает все превью
- На мобильных превью играет **только видимое** (IntersectionObserver, threshold 0.5) — шесть одновременных декодов сажают батарею
- Полноразмерное видео грузится **только по клику** в лайтбоксе, при закрытии `src` снимается
